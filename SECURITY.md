# Security policy

Demain stores personal financial data, so security reports are taken seriously.

## Supported versions

No version has been released yet. Once releases exist, only the latest minor version receives security fixes.

| Version | Supported |
| --- | --- |
| Unreleased (planning) | Not applicable |

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Report it privately through GitHub Security Advisories: open the **Security** tab of the repository, then **Report a vulnerability**.

Please include:

- a description of the problem and its impact
- the steps to reproduce it, or a proof of concept
- the version or image tag affected

Do not include real personal financial data in a report. Use synthetic data.

## What to expect

This is a personal open source project, maintained on a best-effort basis. The targets are:

- acknowledgment of your report within 7 days
- an assessment and a plan within 30 days
- a fix released before any public disclosure, with a disclosure date agreed with you (coordinated disclosure)

You will be credited in the release notes if you wish.
